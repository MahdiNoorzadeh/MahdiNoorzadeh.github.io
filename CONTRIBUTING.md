# Contributing

This repository is primarily a personal portfolio project, so there is no formal contribution process.

If you find a bug, broken link, or other issue, feel free to open an issue with a clear description of the problem.

## Development

To run the project locally:

```sh
git clone https://github.com/MahdiNoorzadeh/MahdiNoorzadeh.github.io.git
cd TerminalPortfolio.github.io
npm install
npm run dev
